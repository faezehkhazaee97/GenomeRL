# GenomeRL

Starter project structure for genome tokenization, RL-based token gating, and downstream evaluation.

## Layout

See the repository tree for the main folders:

- `configs/` experiment and evaluation configuration files
- `data/` raw data, processed artifacts, and dataset splits
- `src/` source code for data, tokenization, models, RL, evaluation, and utilities
- `scripts/` entrypoint shell scripts
- `results/` baseline outputs, RL runs, and generated figures

## Getting Started

1. Create a virtual environment.
2. Install dependencies from `requirements.txt`.
3. Fill in the placeholder config and source files.
